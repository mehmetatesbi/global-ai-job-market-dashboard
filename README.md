🚀 Global AI Job Market Dashboard (2025)
Overview
This project is an interactive, dark-neon Bento Box style Power BI dashboard analyzing over 71,000+ AI & Data job records sourced from Kaggle. It provides comprehensive insights into global compensation trends, job role distributions, company size dynamics, and automation risk exposure across the AI economy.

Features
Bento Box Grid Layout: Modern modular UI design with dark-neon aesthetic for optimal visual hierarchy

Interactive KPI Cards: Real-time metrics for Average Salary, Median Salary, High-Risk Rate, Unique Roles, and Title Diversity

Role Volume & Compensation Analysis: Categorical and experience-level salary breakdowns

Company & Geographical Breakdown: Compensation distribution across company sizes (S/M/L) and top paying countries

Work Model Analysis: Remote, Hybrid, and On-site distribution ratios

Interactive Slicers: Dynamic filtering by work models and experience levels

Data Source
Kaggle (AI Impact on Jobs and Salaries Dataset)

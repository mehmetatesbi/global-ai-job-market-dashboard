# 🚀 Global AI Labor & Wage Intelligence (GALWI)

## Overview
**Global AI Labor & Wage Intelligence (GALWI)** is an interactive, dark-neon **Bento Box style** Power BI dashboard designed to analyze over **71,000+ AI & Data job records** sourced from Kaggle. 

This project delivers high-density labor market intelligence, evaluating global compensation packages, experience-level wage progression, company size distribution, and automation vulnerability across the evolving AI economy.

---

## Features
* **Bento Box Grid Layout:** Modern modular UI design with high-contrast dark-neon aesthetic for optimal visual hierarchy
* **Interactive KPI Cards:** Key performance metrics including Average Salary ($151.16K), Median Salary ($140.00K), High-Risk Automation Rate (6.74%), Unique Roles (422), and Widest Diversity (AI Architect)
* **Role Volume & Compensation Analysis:** Categorical and experience-level wage breakdowns
* **Company & Geographical Dynamics:** Compensation distribution across company sizes (Small, Medium, Large) and top-paying global markets
* **Work Model Analysis:** Remote, Hybrid, and On-site job distribution ratios
* **Dynamic Slicers:** Interactive filtering by work models and experience levels
